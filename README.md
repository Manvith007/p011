# Healthcare Services - Sliding Photos Project

A modern, responsive healthcare website featuring sliding photo galleries and interactive navigation.

## Features

### 🎨 Design
- **Red Header**: Matches the image description with a red header bar containing "My Website" title
- **Blue Footer**: Blue footer with "Thank you for Visiting" message
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices

### 🖼️ Sliding Photos
- **6 Healthcare Images**: Random healthcare-related images from Unsplash
- **Smooth Transitions**: Elegant sliding animations between photos
- **Multiple Navigation Options**:
  - Left/Right arrow buttons
  - Dot indicators at the bottom
  - Keyboard arrow keys
  - Touch/swipe on mobile devices
- **Auto-slide**: Automatically advances every 4 seconds
- **Pause on Hover**: Stops auto-slide when hovering over the slider

### 🍔 Interactive Menu
- **Hamburger Menu**: Three horizontal lines in the header
- **Toggle Functionality**: Click to open/close the menu
- **Smooth Animations**: Animated hamburger icon transformation
- **Dropdown Navigation**: Shows Home, Services, About, and Contact links
- **Click Outside to Close**: Menu closes when clicking outside

### 🎯 User Experience
- **Welcome Section**: Healthcare services introduction
- **Service Cards**: Each slide represents a different healthcare service
- **Hover Effects**: Subtle scaling effects on slide hover
- **Loading Animations**: Smooth image loading transitions
- **Accessibility**: Keyboard navigation support

## How to Use

1. **Open the Project**: Open `index.html` in your web browser
2. **Navigate Photos**: 
   - Click the left/right arrow buttons
   - Use keyboard arrow keys
   - Click the dots at the bottom
   - Swipe on mobile devices
3. **Use the Menu**: Click the hamburger icon (three lines) in the header
4. **Auto-slide**: Photos automatically slide every 4 seconds
5. **Pause Auto-slide**: Hover over the slider to pause
